# IndianPol 2.0 website

Premium responsive static website concept based on the new positioning:

**Build the organization that wins.**

IndianPol is positioned as a political organization platform spanning Build → Campaign → Lead → Grow, from Panchayat to Parliament.

## Replace placeholders

### Founders
In `index.html`, replace the three `.founder` blocks:
- `Founder Name`
- bio text
- `FOUNDER 01/02/03` placeholder

Replace each `.founder-photo` with an `<img>` using the supplied founder image, keeping `object-fit: cover`.

### Work showcase
Replace the three `.work-placeholder` blocks with your actual project images and case-study copy.

### Contact
Update `hello@indianpol.com` to the final contact address if different.

## Run locally
Open `index.html` in a browser. No build step is required.
